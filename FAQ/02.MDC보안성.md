Defender for Cloud는 데이터가 리전을 벗어나지 않도록 설계됨. 한국 리전에서 설정하면, 메타데이터 및 평가 데이터도 한국 내에서 처리됨
다만, 일부 Microsoft Threat Intelligence (글로벌) 기능은 리전 외 데이터를 참고할 수 있음. 
  이때도 데이터 보호 및 GDPR, ISO 기준에 따라 운영됩니다.

---

#### 전송중 암호화, 저장시 암호화
> 전송 중 데이터 암호화(TLS 등): 클라우드용 Microsoft Defender는 데이터 평면에서 전송 중인 데이터를 자동으로 암호화함 (**TLS 1.2**)
> 이 암호화는 기본적으로 활성화됨 , Microsoft가 관리하는 키를 사용해 보안을 유지합니다. 
> 별도의 설정 없이 기본적으로 강력한 암호화를 제공

#### 저장시 암호화
Microsoft Defender for Cloud 사용중, Log Analytics Workspace에 저장되는 데이터는 기본적으로 암호화되어 저장 
Azure의 모든 Log Analytics 데이터는 전송 중에도 암호화되며, 저장될 때는 Microsoft가 관리하는 키(서비스 관리 키, MMK)로 암호화가 자동 적용또한, 
조직의 요구나 규정 준수(컴플라이언스) 필요에 따라 직접 키 관리(Customer Managed Key, CMK)를 선택해서 추가적인 보호 및 독자적인 키 수명 주기 관리를 적용할 수도 있습니다.
> (영문) https://learn.microsoft.com/en-us/azure/security/fundamentals/encryption-atrest <br>

#### 기본로그 보관기간

> Defender for Cloud에서 만든 작업 영역의 경우 데이터는 ⌛ **30일** 동안 보존됩니다
> 기존 작업 영역의 경우 작업 영역 가격 책정 계층에 따라 보존됩니다. 
> 원하는 경우 기존 작업 영역을 사용할 수도 있습니다.
> Defender for Cloud 기준 기본 ⌛ **30일**: 별도 지정하지 않는 한 기본적으로 30일 동안 데이터가 저장·보관됩니다. 
이 기간이 지나면 데이터는 자동으로 삭제됩니다.

> (영문) https://learn.microsoft.com/ko-kr/azure/defender-for-cloud/defender-for-cloud-planning-and-operations-guide

#### 데이터 삭제(조기 삭제, 수동 삭제) 방법

> 로그 자동 만료: 설정한 보존 기간이 지난 데이터는 자동으로 삭제되어 복구할 수 없습니다.

> 수동 삭제 (특정 데이터의 삭제가 필요할 때):
데이터 삭제 API: Log Analytics 작업 영역에서는 API를 활용해 원하는 테이블에서 특정 조건(예: 날짜, 필드 값 등)에 해당하는 로그 데이터를 직접 삭제할 수 있습니다.
데이터 삭제 API를 사용할 때는 삭제 조건이 정확한지 쿼리(KQL)로 충분히 검증 후 실행해야 하며, 삭제는 비동기로 바로/최대 수 분 내 적용됩니다.
삭제 요청 후 되돌릴 수 없으니 반드시 신중하게 사용해야 합니다.
작업 영역 삭제: 전체 데이터를 완전히 제거하려면 작업 영역 자체를 삭제할 수 있으며, 기본적으로 ⌛ **14일간** "일시 삭제" 상태로 머물다 완전 삭제됩니다. 이 기간 내 복구 가능하며, 영구 삭제 설정도 할 수 있습니다.

> (한글) https://learn.microsoft.com/ko-kr/troubleshoot/azure/azure-monitor/log-analytics/billing/configure-data-retention <br>
